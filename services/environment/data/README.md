# Recorded environment data

## `recorded-weather.json`

| field | value |
|---|---|
| Dataset id | `wireup-reference-coastal-24h` |
| Provenance | **Synthetic.** Generated by a seeded sum-of-harmonics model, committed to this repository. It is not an observation of any real location. |
| Licence | CC0-1.0 — public domain dedication, no attribution required |
| Attribution | None. Cite as `WireUp reference coastal 24h series (synthetic)`. |
| Coverage | 24 hourly samples, `2026-01-01T00:00:00Z` … `2026-01-01T23:00:00Z` |
| Variables | wind speed (m/s), wind direction (deg), air temperature (C), sea temperature (C), barometric pressure (hPa), significant wave height (m), visibility (m) |

### Why synthetic and not real

Phase v07 established that this platform may not make network egress happen silently, and
phase v11 applies the same rule to weather: a bundled dataset is the only source that is
reproducible offline, citable, and licence-clean. A real observational archive would be
better data, but it would arrive with a licence, an attribution obligation and a fetch, and
none of those three can be invented. When a reviewed, licensed upstream source is added, it
arrives as the `LiveProvider` path with an explicit allowlist — never as a default.

### Model

Every variable is a closed-form function of hour index `t`, recorded in the file's `model`
block, so the dataset can be regenerated and diffed:

```
wind_speed_mps   = 6 + 2.5*sin(2*pi*t/24 - 0.6) + 1.5*sin(2*pi*t/8 + 1.1)
wind_direction_deg = (215 + 25*sin(2*pi*t/12)) mod 360
air_temperature_c   = 12 + 3*sin(2*pi*t/24 - 1.2)
sea_temperature_c   = 11 + 1.2*sin(2*pi*t/24 - 1.6)
pressure_hpa        = 1013 + 9*sin(2*pi*t/12 + 0.3)
wave_height_m       = 0.6 + 0.35*sin(2*pi*t/12 + 0.3)
visibility_m        = 18000 - 6000*max(0, sin(2*pi*t/24))
```

### Use in a run

`packages/solvers/environment/weather.mjs` → `RecordedProvider` reads the samples in order,
one per read. The index advances by one per read and never by wall clock, so a replay is
byte-identical on every machine. Every sample it returns carries a `source` object naming the
dataset, its provider, its licence and its path, and every telemetry sample derived from it
inherits that provenance — a weather number without a stated source is not evidence.
